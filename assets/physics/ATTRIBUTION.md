# Physics Workshop 3D assets

## Car Concept

- Source: Khronos glTF Sample Assets, `CarConcept.glb`
- Original model: Unity Fan
- Repository: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept
- License: public domain / CC0 source asset as documented by Khronos

The model is stored locally so the interactive lesson works without third-party requests at runtime. The detailed engine shown in the cutaway is built in code (`buildDetailedEngine` in `js/worlds/physics.js`).
