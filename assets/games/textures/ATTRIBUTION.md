# Game Room textures

All textures in this folder come from [Poly Haven](https://polyhaven.com) and are dedicated to the public domain under **CC0 1.0**. They were downscaled and recompressed for the web.

| File prefix | Poly Haven asset |
|---|---|
| `asphalt_02` | https://polyhaven.com/a/asphalt_02 |
| `castle_wall_slates` | https://polyhaven.com/a/castle_wall_slates |
| `oak_veneer_01` | https://polyhaven.com/a/oak_veneer_01 |
| `wood_table_001` | https://polyhaven.com/a/wood_table_001 |

The race and castle meadows also use `assets/math/textures/leafy_grass-*` (CC0, Poly Haven).
